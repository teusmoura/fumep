# AGENTS.md — packages/ui

Escopo: Design System e renderers compartilhados.

## Regras
- Componentes institucionais são resolvidos por tokens/ThemeContext.
- Não criar FumepButton/EtmslButton/CramamButton.
- Componentes interativos devem funcionar por teclado.
- Sem cores arbitrárias fora dos tokens quando houver token aplicável.
- Preservar mobile-first e dark mode.
- Renderers de ContentBlock devem ser reutilizáveis entre Preview e público.

## Validação
Testes de componente quando aplicáveis e acessibilidade básica.
