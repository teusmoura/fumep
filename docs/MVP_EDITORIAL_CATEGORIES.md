# MVP — catálogo editorial de categorias

O loop MIG 5.8-CAT entrega um catálogo real via FastAPI/PostgreSQL, **sem interface Nuxt conectada**. As rotas `GET/POST /api/v1/admin/categories` e `GET/PUT/DELETE /api/v1/admin/categories/{id}` aparecem em `/docs`. Mutações exigem sessão Redis, `Origin`/`Referer` da aplicação e `X-CSRF-Token` retornado pelo login. Categoria global (`institution_id: null`) é administrada somente por ADMIN; categoria institucional pode ser administrada por ADMIN ou EDITOR atribuído. Leitura global está disponível a usuários autenticados. Slug é único dentro de cada instituição e globalmente no escopo nulo.

A migration `20261005_02` e os testes de CRUD foram executados apenas em `portal_fumep_mig58_test`. Para executar a suíte de integração, fornecer `FUMEP_TEST_DATABASE_URL` apontando **exatamente** para esse banco local já migrado e rodar `python -m pytest -q tests/test_categories_http.py tests/test_page_template_database.py` dentro de `apps/backend`. `FUMEP_TEST_REDIS_URL` opcional troca fakeredis pelo Redis real; as sessões de teste usam prefixo aleatório `migration:cat-test:` e são invalidadas no teardown. Não apontar a API de categorias para `portal_fumep` antes da auditoria/adopção das migrations Python: ali a tabela ainda não existe. Nenhuma senha ou conta de demonstração é versionada.
