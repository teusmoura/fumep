# Next.js Frontend

1. Leia `apps/web/AGENTS.md`.
2. Leia arquitetura de Frontend.
3. Determine InstitutionContext pela rota.
4. Reuse componentes do Design System.
5. Server rendering por padrão para conteúdo público.
6. Client Component só para interação.
7. Verifique teclado, foco, responsividade e dark mode.
8. Não faça autorização apenas visual.
9. Adicione testes aplicáveis.
10. Rode checks.

Regra:
Um componente compartilhado + ThemeContext é preferível a três componentes institucionais.
